# Persian GIF Telegram Bot (ربات گیف فارسی)

یک ربات سریع، سبک و رایگان برای جستجو و ارسال گیف و میمهای متحرک فارسی در تلگرام، توسعهدادهشده با **TypeScript**، **grammY** و اجرا روی **Cloudflare Workers** با دیتابیس **Cloudflare D1 (FTS5)**.

---

## ویژگیهای کلیدی

- **سرعت بالا (کمتر از ۲۰۰ میلیثانیه):** به دلیل اجرای سرورلس روی سرورهای لبه (Edge) کلودفلر و دیتابیس بومی D1.
- **هزینه سرور و استوریج صفر:** استفاده از کانال تلگرام به عنوان CDN نامحدود فایلها با `file_id`.
- **جستجوی تماممتنی (FTS5):** جستجوی سریع و هوشمند روی عنوانها، تگها و هشتگهای فارسی به همراه نرمالایزر اختصاصی الفبای فارسی و نیمفاصله.
- **امنیت بالا:** اعتبارسنجی خودکار هدر `X-Telegram-Bot-Api-Secret-Token` و عدم امکان نفوذ به وبهوک.
- **بهینهسازی ترافیک با کش تلگرام:** استفاده از `cache_time` برای کاهش بار پردازشی ورکرز و ماندن در سقف پلن رایگان کلودفلر.
- **معماری مقیاسپذیر:** ساختار دیتابیس آماده برای اضافه شدن رایگیری جامعه، سیستم امتیازدهی و صف تایید ادمین در آینده.

## ساختار پروژه

```text
persian-gif-bot/
├── .specify/                 # فایلهای مشخصات و اصول پروژه (Spec-Kit)
├── specs/                    # سناریوها، تسکها و قراردادهای مهندسی
├── schema.sql                # اسکیما و تریگرهای دیتابیس D1 و FTS5
├── wrangler.toml             # پیکربندی Cloudflare Workers
├── package.json
├── tsconfig.json
└── src/
    ├── index.ts              # هندلر اصلی ورکر و اعتبارسنجی سکرت توکن
    ├── bot.ts                # پیکربندی ربات grammY
    ├── handlers/
    │   ├── inline.ts         # پردازش جستجوی اینلاین (@bot query)
    │   ├── channel.ts        # ایندکس خودکار گیفهای ارسالی به کانال استوریج
    │   └── commands.ts       # دستورات /start و راهنما
    ├── db/
    │   ├── queries.ts        # توابع کار با دیتابیس D1
    │   └── sanitize.ts       # نرمالایزر متن فارسی و FTS5
    └── types/
        ├── env.ts            # تایپهای محیطی ورکر (Bindings)
        └── gif.ts            # تایپهای انتیتی گیف
```

## راهاندازی و اجرای محلی (Local Development)

### ۱. نصب پکیجها

```bash
npm install
```

### ۲. ساخت دیتابیس محلی و اعمال اسکیما

```bash
# ایجاد دیتابیس محلی D1
npm run db:local
```

### ۳. اجرای سرور توسعه ورکر

```bash
npm run dev
```

## دیپلوی و راهاندازی روی Cloudflare (Production)

### ۱. لاگین در کلودفلر با Wrangler

```bash
npx wrangler login
```

### ۲. ساخت دیتابیس D1 در کلودفلر

```bash
npx wrangler d1 create persian-gif-db
```
شناسه `database_id` نمایش داده شده را در فایل `wrangler.toml` جایگزین کنید.

### ۳. اعمال اسکیما روی دیتابیس سرور

```bash
npm run db:remote
```

### ۴. تنظیم توکنهای محرمانه در ورکر

```bash
npx wrangler secret put BOT_TOKEN
# توکن دریافتی از BotFather را وارد کنید

npx wrangler secret put SECRET_TOKEN
# یک رشته تصادفی امن برای اعتبارسنجی وبهوک وارد کنید
```

### ۵. انتشار ورکر (Deploy)

```bash
npm run deploy
```

### ۶. تنظیم وبهوک تلگرام

آدرس ورکر منتشرشده را به تلگرام معرفی کنید:

```bash
curl -F "url=https://<your-worker-subdomain>.workers.dev/webhook" \
     -F "secret_token=<YOUR_SECRET_TOKEN>" \
     -F "allowed_updates=[\"message\",\"inline_query\",\"channel_post\",\"edited_channel_post\"]" \
     https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook
```

### ۷. فعالسازی حالت اینلاین در BotFather

1. وارد ربات `@BotFather` شوید.
2. دستور `/setinline` را ارسال کرده و ربات خود را انتخاب کنید.
3. یک متن پیشفرض برای پلیسهولدر تعیین کنید (مثلاً `جستجوی گیف فارسی...`).

## نحوه استفاده و ثبت گیف

1. یک کانال تلگرام خصوصی بسازید و ربات را به عنوان **ادمین** در آن اد کنید.
2. آیدی عددی کانال را در `wrangler.toml` (یا سکرتها) به عنوان `STORAGE_CHANNEL_ID` تنظیم کنید.
3. یک گیف یا ویدیو را با کپشن و هشتگ در کانال ارسال کنید:
   ```text
   گربه خنده دار و بامزه #گربه #طنز #خنده
   ```
4. ربات به صورت خودکار پیام را پردازش کرده و آن را در موتور جستجوی D1 ایندکس میکند.
5. حالا در هر چتی میتوانید بنویسید:
   ```text
   @your_bot_username گربه
   ```
